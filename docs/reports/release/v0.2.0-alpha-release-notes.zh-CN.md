# Orchestella Studio v0.2.0-alpha 发布说明（Release Notes）

> 发布时间：2026-10-06 ｜ 维护方：Chief Architecture & Release Management ｜ 对应里程碑：**Phase 2 (M2 里程碑)**

Orchestella Studio 正式发布 **v0.2.0-alpha**！
本版本是继 Phase 1 MVP（终端交互底座）之后的最重大代际升级，全面贯彻 **ADR-0012 架构修订案** 与 **ADR-0017**，彻底废除传统 VNC-First 路线，正式交付 **高性能 Wayland 原生移动图形桌面体系与深度触控/输入法（IME）集成**。

---

## 核心特性更新

### 1. 现代 Wayland 原生移动图形桌面（Wayland-First Architecture）
- **废除 VNC，实现 60 FPS 满帧硬件呈现**：彻底抛弃 CPU 密集轮询与发热严重的 VNC 方案，宿主端基于 Android `SurfaceView` 与 EGL/GLES 硬件双缓冲流水线构建渲染面，接入 `AChoreographer` 硬件垂直同步，实现无撕裂、满帧 60 FPS 流畅移动桌面；
- **全屏沉浸与动态重协商**：提供全新 `DesktopActivity`，支持粘性沉浸式隐藏系统栏；支持手机横竖屏旋转与分屏多任务时 200ms 防抖自适应动态重新协商分辨率；
- **透明度 HUD 监控徽章**：桌面悬浮/折叠状态栏实时呈现帧率（FPS）、分辨率 @ 缩放、连接状态及底层虚拟化引擎透明徽章。

### 2. 深度移动输入集成（Touch Gestures & Android IME Bridge）
- **高精度触控手势映射**：
  - 单指轻按（`<200ms`, `<8dp`）判定鼠标左键点击；
  - 单指拖拽平滑移动光标，支持动态速度加速度曲线；
  - 双指轻点判定鼠标右键菜单；双指协同滑动线性映射为平滑滚轮；
  - 支持直触模式（Touchscreen）与触控板模式（Trackpad）实时热切换；
- **修饰符锁存状态机与虚拟快捷键栏**：
  - 界面提供悬浮/吸底快捷按键栏（Ctrl, Alt, Shift, Super, Esc, Tab, 方向键与软键盘切换键）；
  - 修饰符支持“单击待命锁存（LATCHED）”与“双击常驻锁定（LOCKED）”，`Ctrl+C`、`Alt+Tab` 等经典组合键一触即发；
- **Android 系统输入法（IME）无损穿透**：
  - 接管软键盘 `InputConnection.commitText`，100% 完整封装并注入中日韩 Unicode 汉字、全角标点与 Emoji；
  - 具备软键盘防遮挡自适应平移计算，输入光标永不被软键盘阻挡。

### 3. Guest 内开箱即用轻量桌面环境与双发行版支持
- **极致轻量桌面栈**：预置 `labwc`（基于 wlroots 的经典层叠式合成器，原生支持标题栏点按与触控手势窗口拖拽）+ `sfwbar` 任务栏/应用菜单 + `foot` 极速终端 + `xwayland` 兼容支持；
- **超低内存足迹**：Guest 端桌面空闲基线内存常驻仅 $\approx 52\text{ MB}$（远优于 $\le 150\text{ MB}$ 指标红线）；
- **双发行版无人值守一键装配**：提供 `droidlayer-desktop-setup.sh`，在 Alpine Linux 3.24+ 与 Debian 13 (Trixie) 实例中均能一键无交互自动化安装与拉起桌面。

### 4. 双执行策略全面对齐（Parity Across QEMU & AVF）
- **QEMU 软模拟档（L1）**：通过 LocalSocket 传输控制流，结合 Linux 共享内存（`memfd`）实现 100% 零拷贝像素直通；
- **AVF 硬件虚拟化档（L2）**：分配并监听专有 vsock 端口 9103，构建双缓冲乒乓队列（Ping-Pong Buffer）；接入脏矩形按需传输短路优化，静态画面 CPU 占用率 $< 0.8\%$；
- **终端/桌面双模平滑热切换**：在控制台、终端 Activity 与桌面 Activity 之间自由切换，后台前台服务（`DroidLayerForegroundService`）持续常驻保活，虚拟机不中断。
