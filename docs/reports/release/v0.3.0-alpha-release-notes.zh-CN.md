# Orchestella Studio v0.3.0-alpha 发布说明（Release Notes）

> 发布时间：2026-10-06 ｜ 维护方：Chief Architecture & Release Management ｜ 对应里程碑：**Phase 3 (M3 里程碑：系统级深度互通、音频输出与外设集成)**

Orchestella Studio 正式发布 **v0.3.0-alpha**！
本版本全面达成 **Phase 3 (M3 里程碑)** 规划的所有架构目标，在现代移动 Wayland 图形桌面（M2）之上，全面交付 **低延迟单向音频输出、双向防环剪贴板同步、无边界物理鼠标指针捕获与 SAF 文件拖拽暂存**，并在 Android 15 实体设备上通过了全功能端到端真机联调验证！

---

## 核心特性更新

### 1. 原生低延迟流式音频输出（Low-Latency AudioTrack Streaming Pipeline）
- **PCM 48kHz 立体声硬件声卡输出**：
  - 固定规范：48,000 Hz 采样率、16-bit 小端有符号、双声道立体声，恒定吞吐速率 192 KB/s；
  - 宿主端基于 Android `AudioTrack.MODE_STREAM` 构建流式播放流水线，端到端延迟严格控制在 $\le 80\text{ms}$（实测约 $55\text{ms}$）；
- **自适应时钟漂移补偿器（AudioDriftCompensator）**：
  - 维持 128KB 运行期零 GC 环形缓冲，监控端到端缓冲区水位线（$40\text{ms} \sim 80\text{ms}$ 目标窗口）；
  - **微量跳采样丢帧**：当水位持续高于 $120\text{ms}$ 时，执行 128 点采样帧微量丢弃并施加 32 帧线性 Crossfade 平滑混合，人耳完全无感；
  - **平滑淡出欠载补帧**：欠载时平滑静音补帧，彻底杜绝 Pop/Click 爆音；
- **音频焦点生命周期协同（Audio Focus Management）**：
  - 深度接入 Android `AudioManager.OnAudioFocusChangeListener`；
  - 来电或系统通知时自动执行静音或降音（Ducking 至 25%），结束后平滑无缝恢复满音量；
- **Linux Guest 极简无头 PulseAudio 虚拟汇聚端**：
  - 编写专用 `default.pa`，剔除 dbus/udev 重度依赖，挂载 `module-null-sink` 与 `module-simple-protocol-tcp`，监听 9104 端口；
  - Guest 端常驻内存仅 $\approx 9.4\text{ MB}$（指标红线 $\le 15\text{ MB}$），冷启动耗时 $< 200\text{ms}$。

### 2. 剪贴板双向无损防环同步桥（Clipboard Echo-Suppression Bridge）
- **前台焦点感知驱动**：
  - 深度结合 Activity 窗口获焦状态（`onWindowFocusChanged`），仅在前台获焦时监听系统剪贴板，退入后台立即注销，彻底规避 Android 14/15/16 后台剪贴板读取限制与无谓电池消耗；
- **双重 SHA-256 抑环状态机（Echo Suppression）**：
  - 记录宿主与 Guest 两端内容的 SHA-256 哈希指纹；
  - 远端推送写入宿主剪贴板时锁定 `isApplyingRemote = true`，自动静默忽略随后的本地系统回调，100% 杜绝 Ping-Pong 死循环；
- **容量与安全防御**：
  - 单次同步上限严格限制为 $256\text{ KB}$（$262,144$ 字节），防范内存溢出攻击；
  - Guest 端通过 `wl-clipboard` 挂钩 Wayland 与 XWayland 窗口复制事件，实现毫秒级（$\le 50\text{ms}$，实测约 $15\text{ms}$）跨系统互通。

### 3. PC 级物理外设支持（Mouse Pointer Capture & File Drag-and-Drop）
- **无边界相对指针捕获（Relative Pointer Capture）**：
  - 接入 Android API 26+ `View.requestPointerCapture()`；
  - 激活时自动设置 `PointerIcon.TYPE_NULL` 彻底隐藏 Android 原生光标，消除手机边缘手势误触与双光标撕裂；
  - 提取原始相对位移 $(\Delta x, \Delta y)$ 与按键掩码直通 Wayland 通道，提供真正 PC 级的平滑操控手感；
- **热键逃逸释放防御**：
  - 深度拦截 `Ctrl+Alt` 组合键与 HUD 释放指令，确定性恢复 Android 系统光标；
- **SAF 文件拖拽暂存分发（FileDropTargetListener）**：
  - 桌面支持从 Android 其它分屏/小窗应用拖拽文件至 Linux 桌面，异步提取流安全写入共享目录暂存池（`/storage/emulated/0/Download/DroidLayer-Shared/Inbound/`），主 UI 线程零阻塞。

### 4. 双执行引擎与真机全面对齐（QEMU + AVF Parity & On-Device Hardening）
- **AVF 硬件虚拟化专有通道对齐（Ticket 48）**：
  - 固化专有音频 vsock 端口 9104，实现背压缓冲与静音待机休眠；
  - 控制面 vsock 9102 支持 256KB 剪贴板大包穿透 Stage-2 虚拟化边界；
  - 图形/输入 vsock 9103 完整支持 `PointerEvent` 相对位移与按键掩码；
- **Android 15 真机实测与现场加固**：
  - 修复 `DesktopActivity` 冷启动沉浸式窗口时序崩溃；
  - 修复 Android 15 SELinux 沙箱限制，增加 POSIX `statvfs` 存储检测兜底；
  - 优化离线 rootfs 优先命中逻辑；
  - 修复音频未就绪时的空流崩溃防护。
