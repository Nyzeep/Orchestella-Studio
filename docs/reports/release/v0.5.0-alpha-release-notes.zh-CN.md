# Orchestella Studio v0.5.0-alpha 发布说明

> 发布时间：2026-10-10 ｜ 维护方：Orchestella Architecture & Release Engineering ｜ 里程碑：**Phase 5.0 (移动工作站体验大闭环与发版冲刺)**

Orchestella Studio 正式发布 **v0.5.0-alpha**！
这是自 v0.4.0 以来最具里程碑意义的重大全栈升级。经过 Phase 4.6 至 Phase 5.0 的连续深水区战役，项目完成了从**移动高分屏桌面适配**、**字符级交互行即打即显终端**、**全栈 Material 3 人体工程学重塑**，到**多模触控板手势**、**多实例生命周期治理**与**整机冷备份导入导出**的全方位进化。

---

## 🌟 核心突破与功能亮点

### 1. 现代化即打即显终端与智能补全（Phase 4.7 ~ 5.0）
- **字符级按键即时回显（Real-time Keystroke Echo）**：彻底告别弹窗式整行输入，击键、退格与控制序列即时在当前屏幕行原位渲染；
- **全功能光标导航与任意位置编辑**：支持左右方向键自由移动光标，行内文本无闪烁精准插入、退格与 Delete 擦除；
- **风格化 Prompt 视觉**：集成类似 Starship / Windows Terminal 风格化胶囊提示符；
- **Linux 常用命令 Tab 智能补全**：内置 40+ 常用 Linux 核心命令字典，支持管道符（`|`）与复合控制符切词、最长公共前缀（LCP）渐进补全与多候选词列表友好格式化展示；
- **命令历史跨会话原子持久化**：落地 `TerminalHistoryStore`，支持单实例 500 条命令记录 Base64 安全持久化，Activity 重建或关闭重启后历史不丢失；
- **移动端触控辅助按键栏重塑**：全量按键满足 Material 3 触摸靶心标准（$\ge 48\times 48\text{ dp}$），扩充 `CLR`（一键清屏）、`PASTE`（剪贴板粘贴）、`HOME` / `END`（行首尾跳转）高频操作。

### 2. Wayland 原生移动图形桌面与 High-DPI 缩放（Phase 4.6 ~ 4.9）
- **高分屏 High-DPI 动态缩放**：针对 2K+ 高密度移动屏幕（如 560 DPI）自适应协商 $\ge 2.0\text{x}$ 界面缩放，彻底消除界面字体过小的痛点；
- **双模触控状态机（Direct Touch / Virtual Trackpad）**：
  - **直接触摸模式**：手指点击直接映射 Wayland 绝对坐标，适合大按钮与常规触屏；
  - **虚拟触控板微操模式**：手机化身精密触控板，手指滑动产生相对位移控制指针，彻底解决高分屏微小控件难以精准点击的问题；
- **手势防抖与阻尼平滑**：引入 `0.85f` 阻尼因子与 `2.0px` 死区阈值，单指点击（左键）、双指轻触/长按（右键）、双指滑动（滚轮 `wl_pointer.axis`）；
- **悬浮操作指示胶囊**：桌面顶部集成一键模式切换胶囊与灵敏度微调设置。

### 3. 多实例资产治理与存储深度管控（Phase 4.9 ~ 5.0）
- **实例物理彻底删除与空间回收**：支持擦除 raw 稀疏磁盘镜像与配置，释放宿主物理存储；
- **实例一键极速深拷贝克隆**：支持从现有实例一键衍生出同构隔离的全新分支；
- **实例硬件规格动态调整向导**：允许在停止状态下自由升降配 vCPU 核心数（1~8 核）、RAM 内存上限（512M~8GB，保留 $\ge 2\text{GB}$ 宿主防 OOM 内存防线）与稀疏盘增量扩容；
- **基于 SAF 的整机冷备份导出与完整性导入恢复**：支持流式打包导出为备份文件，导入时采用 64KB 块缓冲在线 SHA-256 校验，带异常零泄漏安全回滚。

### 4. 系统级互通与动态网络管理（Phase 4.6 ~ 4.8）
- **双向防回环剪贴板同步桥**：严格遵循 ADR-0018 规范，基于前台焦点感知、SHA-256 哈希比对与 256KB 容量上限，彻底打通 Android 宿主与 Linux Guest 剪贴板；
- **动态端口转发管理面板**：提供 Material 3 规范的运行态端口映射管理底栏，支持非特权端口（1024~65535）输入防错与协议冲突检测；
- **低延迟音频通道**：内置 PulseAudio 48kHz PCM 单向低延迟音频流通道。

### 5. 全栈品牌收敛与架构纯净度（Phase 4.7 & 4.9）
- 全栈代码、包名（`io.github.nyzeep.orchestella.*`）、Android 清单与脚本全面收敛至统一品牌 **Orchestella**；
- 全域工单决策地图与历史架构资产规整至 `.scratch/orchestella-platform/`。
