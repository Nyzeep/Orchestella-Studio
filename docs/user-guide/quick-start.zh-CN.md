# Orchestella Studio 快速上手指南（新手小白专版）

> **适用版本**：Orchestella Studio 0.3.0-alpha+ (Phase 4 / M4)  
> **适用对象**：初次接触移动端 Linux 虚拟化、希望在 Android 手机或平板上运行独立 Linux 系统的用户  
> **核心原则**：免 Root、独立内核、高安全隔离、开箱即用

---

## 1. 什么是 Orchestella Studio？

**Orchestella Studio（DroidLayer）** 是一款在 Android 操作系统上运行的专业级、免 Root 虚拟化应用。与传统的 Termux（基于 PRoot 命名空间与系统调用劫持）不同，Orchestella Studio 在手机中启动了**真正的独立 Linux 内核**与虚拟硬件设备，拥有独立的进程空间、独立的文件系统、独立的虚拟网络以及近原生的安全隔离能力。

### 为什么选择 Orchestella Studio？
- 🛡️ **真正免 Root**：无需解锁手机 Bootloader，不破坏系统保修，不触发 Knox / 银行应用风控；
- 🐧 **完整 Linux 生态**：运行标准发行版（Alpine / Debian），支持标准 `glibc` / `musl`，原生支持标准 Linux 软件包与服务；
- 🖥️ **60 FPS 流畅图形桌面**：独创 Wayland 原生图形直通通道，配合 GPU 3D 硬件加速，移动端也可拥有媲美 PC 的桌面交互体验；
- ⚡ **智能硬件感知**：自动探测手机的芯片算力与内存大小，精准推荐防闪退的安全参数。

## 2. 安装与首次启动向导（Setup Wizard）

### 2.1 获取与安装
1. 下载 Orchestella Studio 最新 Debug 或 Release APK 安装包（`Orchestella-Studio-v0.3.0-alpha.apk`）；
2. 在手机文件管理器中点击安装包。若系统提示“允许来自此来源的应用”，请在系统弹窗中开启授权并完成安装；
3. 打开桌面图标 **Orchestella Studio**。

### 2.2 首次启动三步闭环向导
应用启动时会自动检测是否为首次使用。若尚未完成环境配置，应用将无感拉起**首次启动三步向导（Setup Wizard）**，引导您轻松搞定初始环境：

```
┌──────────────────────────────────────────────────────────────────┐
│                   首次启动三步闭环向导流程                       │
└──────────────────────────────────────────────────────────────────┘
   第 1 步：环境感知        第 2 步：发行版选单        第 3 步：推荐配置与就绪
  ┌───────────────┐        ┌───────────────┐        ┌───────────────────┐
  │ 探测芯片架构  │  ───▶  │ Alpine (极轻量)│  ───▶  │ 自动计算安全内存 │
  │ 探测物理核心  │        │       vs      │        │ 弹性断点续传下载  │
  │ 探测虚拟化引擎│        │ Debian (全生态)│        │ 校验并创建实例    │
  └───────────────┘        └───────────────┘        └───────────────────┘
```

#### 第一步：宿主环境与虚拟化感知
- **硬件指标自检**：系统将自动读取您手机的芯片架构（如 `arm64-v8a`）、CPU 物理核心数（如 8 核心）、总内存与可用内存、以及手机存储空间；
- **虚拟化运行引擎探测**：
  * 🎉 **L2 硬件虚拟化已就绪**：若您的系统开放了 Android 虚拟化框架（AVF/pKVM），将以近原生性能运行；
  * ⚡ **可解锁硬件虚拟化**：若设备支持但缺少开发权限，界面将提供“获取授权指引”按钮，可通过电脑 ADB 或免电脑的 Shizuku 一键激活；
  * 💡 **Class A 软模拟引擎就绪**：如果您的机型不支持 AVF 或选择跳过授权，**请完全放心**！Orchestella Studio 预置经过深度调优的 QEMU 运行时，无需任何权限即可开箱即用。
- 点击底部**「下一步」**进入发行版选择。

#### 第二步：选择您的首个 Linux 发行版
应用精选了移动端体验最佳的两大发行版供您选择（后续在主界面随时可以增减或并存）：

| 维度对比 | ⚡ Alpine Linux 3.24 | 🐧 Debian GNU/Linux 13 (Trixie) |
| :--- | :--- | :--- |
| **镜像体积** | **约 4 MB**（数秒即可拉取完毕） | 约 90 MB（几分钟内就绪） |
| **开机运存占用** | **仅约 30~50 MB**（极低负荷） | 约 150~250 MB |
| **包管理器** | `apk`（以轻巧和极速著称） | `apt`（浩瀚生态、兼容性标杆） |
| **适用人群与场景** | 移动端日常敲命令、轻量脚本、极客容器 | 完整桌面体验、Python/Rust 开发、编译工作流 |
| **新手推荐指数** | ⭐⭐⭐⭐⭐（**首选推荐，极速上手**） | ⭐⭐⭐⭐（适合有明确软件包需求的用户） |

- 点击对应卡片即可切换选中（选中项将呈现高亮绿框与「✓ 当前选中」徽标）；
- 选定后点击**「下一步」**。

#### 第三步：推荐配置确认与一键弹性初始化
- **智能防闪退配额**：
  * 许多虚拟机应用因为内存分配过多，导致手机触发系统级杀后台（Low Memory Killer）。
  * Orchestella Studio 会根据您的物理内存，自动计算最安全的配额，**强制保留至少 2GB 内存给 Android 宿主系统**，同时保留 1 个 CPU 核心处理宿主界面交互，彻底远离卡顿与闪退。
- **弹性断点下载**：
  * 点击**「🚀 立即初始化首个实例」**；
  * 系统将启动自适应弹性下载引擎，内置官方 CDN 与国内清华大学、中科大高速镜像源；遇到弱网断流会自动重试与断点续传；
  * 进度条实时展示已下载大小、下载速率（MB/s）与预计剩余时间；
  * 下载完成后系统将自动校验 SHA-256 哈希值、初始化根磁盘卷，并带您自动进入主界面！

## 3. 首次 Shell 命令行与图形桌面初体验

### 3.1 连接终端（Terminal）
进入主界面后，您会看到刚刚创建好的实例卡片（例如 `Alpine Linux 3.24.1`）。
1. 点击卡片上的**「打开终端」**按钮（或长按卡片在底部菜单中选择「打开终端控制台」）；
2. 稍等片刻，您将看到极具极客风格的终端控制台，已为您默认装配工业标杆 **Dracula 深色高对比调色板** 与现代化 Shell 提示符；
3. 输入以下命令测试系统状态：
   ```bash
   uname -a      # 查看 Linux 内核版本与独立架构
   free -m       # 查看当前虚拟机的内存使用情况
   df -h         # 查看虚拟根磁盘的容量
   ```

### 3.2 安装第一个常用工具
在终端中，您可以像在专业服务器或树莓派上一样安装软件：

- **若是 Alpine Linux 实例**：
  ```bash
  # 1. 刷新软件源列表
  apk update

  # 2. 安装 curl、git 和炫酷的系统信息工具 neofetch
  apk add curl git neofetch

  # 3. 运行 neofetch 展现 Linux 企鹅图标与系统配置
  neofetch
  ```

- **若是 Debian Linux 实例**：
  ```bash
  # 1. 更新 apt 索引
  apt update

  # 2. 安装基础工具
  apt install -y curl git neofetch

  # 3. 运行 neofetch
  neofetch
  ```

### 3.3 体验 60 FPS 流畅图形桌面
如果您的实例支持图形桌面：
1. 在主界面实例卡片上点击**「启动图形桌面」**；
2. 应用将无缝切换至沉浸式全屏桌面视图（Wayland 客户端），享受独立图形渲染带来的顺滑操控；
3. 从屏幕边缘内滑或点击悬浮窗，可随时返回主界面或在终端与桌面之间双向切换。

## 4. 移动端高频实用操作技巧

为了让手机与平板上的 Linux 交互更加高效，Orchestella Studio 专门针对移动触控场景研发了多项辅助利器：

### 4.1 移动辅助按键栏（KeyBar）
手机软键盘通常没有电脑键盘的特殊功能键。当您打开终端时，软键盘上方常驻一排专用辅助快捷键：
- **`ESC` 键**：在 Vim 编辑器中秒退编辑模式，或在命令行中取消当前输入；
- **`TAB` 键**：命令行神级按键！输入文件名前几个字符点击一次即可自动补全，连按两次列出所有匹配项；
- **`CTRL` 与 `ALT` 键**：支持**粘滞模式（Sticky Mode）**！点击一下 `CTRL` 键会高亮锁定，紧接着在输入法上按 `c`，即可发送 `Ctrl+C` 中断正在运行的程序；
- **`↑` / `↓` 方向键**：快速上下翻阅历史输入过的命令，免去重复打字的烦恼；
- **管道符 `|` 与常见符号**：单机直接输入命令行中极度常用的管道符 `|`、波浪号 `~`、斜杠 `/` 与反斜杠 `\`。

### 4.2 双向剪贴板（手机 ⇋ Linux 无缝复制粘贴）
Orchestella Studio 搭载了独创的防死循环双向剪贴板通道：
- **从手机复制到 Linux**：在微信、网页或笔记中长按复制一段代码或网址，切换到 Orchestella Studio 终端中，长按屏幕点击「粘贴」即可；
- **从 Linux 复制到手机**：在 Linux 终端中高亮选中的文本会自动同步到 Android 系统的系统剪贴板，您可直接切到手机聊天框粘贴分享。

### 4.3 外接蓝牙/有线键鼠与扩展屏支持
如果您拥有一台平板或支持视频输出的手机，外接键鼠能瞬间化身便携 Linux 工作站：
1. **连接键鼠**：通过蓝牙或 USB-C OTG 扩展坞连接实体键盘与鼠标；
2. **指针捕获**：在图形桌面中，点击屏幕右上角或顶部菜单的「捕获鼠标」，鼠标滚轮、左右键与移动将 1:1 直通进 Linux 系统；
3. **释放指针**：当需要切回 Android 系统时，按下快捷键 `Ctrl + Alt`，鼠标光标即刻解除捕获返回手机界面。

### 4.4 手机后台长效保活指南
为了防止手机锁屏或切换应用时系统把 Linux 虚拟机杀死：
1. **开启前台通知**：应用运行时系统通知栏常驻保活卡片，请勿划掉该通知；
2. **设置电池无限制**：
   * 前往手机系统「设置」 -> 「应用管理」 -> 「Orchestella Studio」；
   * 找到「耗电管理」或「电池优化」，将其设为**「无限制」**或**「允许后台高耗电」**；
3. **应用卡片加锁**：在手机多任务后台列表中，下拉 Orchestella Studio 卡片并点击“锁定”小锁图标。

## 5. 常见问题解答（FAQ）

### Q1：下载镜像时提示“网络失败”或长时间无进度怎么办？
> **答**：下载引擎内置了自动多源切换机制。如果遇到跨境网络波动，系统会在 15 秒后自动重试并切换至国内清华镜像节点。您也可以检查手机是否开启了飞行模式或局域网代理阻断，确保数据网络畅通后重试即可。

### Q2：我创建了两个实例，可以同时开机运行吗？
> **答**：为保护手机电池寿命与避免整机发热卡顿，Orchestella Studio 严格遵循单活动运行策略（Single Running Instance）。若想启动第二个实例，请先在当前实例中输入 `poweroff` 关机，随后即可自由启动另一个实例。

### Q3：如果实例损坏或不需要了，如何彻底释放存储空间？
> **答**：在主界面长按实例卡片（或点击卡片右上角的 `⋮` 菜单），点击**「🗑️ 彻底物理删除」**并二次确认。系统会物理清除底层全部磁盘文件与缓存，100% 彻底释放手机私有空间，不留任何残留。
